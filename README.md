# Учебный проект "Умный дом" для курса OTUS Rust Developer.Professional
- (группа Rust-Pro-2025-02)

#### Примеры

-   `cargo run --example basic` - базовый пример формирование отчета для умного дома из нескольких комнат

#### Тесты
- `cargo test` - запуск всех тестов
- `cargo test <test_name>` - запуск определенных тестов
- `cargo test <test_name> -- --nocapture` - запуск определенных тестов с выводом в консоль сообщений (println!, dbg! и т.п.)
